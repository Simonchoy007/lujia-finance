噜家理财操作说明书

每月操作流程

  1. 输入编辑密码进入编辑模式
  2. 每月资金规划填入到手收入、各类支出
  3. ETF页面手动录入期末市值
  4. 录入股票最新价格
  5. 点击【保存到云端】；家人刷新网页即可看到更新
  6. 定期导出JSON备份文件保存本地电脑

权限说明

不输入密码打开网页：全部输入框禁用，仅只读浏览；只有输入正确编辑密码，才能修改数据并保存云端。

风险纪律

  • 个股浮亏25%无条件止损；禁止亏损补仓
  • 应急赎回不能中断定投；信号空白期不操作
